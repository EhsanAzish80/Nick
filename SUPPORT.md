# Support

## Before requesting help

1. Confirm that Nick came from the
   [official releases page](https://github.com/EhsanAzish80/Nick/releases).
2. Record the Nick version, build number, macOS version, and Mac model.
3. Run Smart Scan and note which protection check is not ready.
4. Review the [User Guide](Documentation/USER_GUIDE.md) and
   [installation requirements](README.md#installation).
5. Remove secrets, email content, usernames, and unrelated file paths from
   screenshots and logs.

## Where to ask

- Reproducible bug:
  [open a bug report](https://github.com/EhsanAzish80/Nick/issues/new?template=bug_report.yml)
- Incorrect detection:
  [report a false positive](https://github.com/EhsanAzish80/Nick/issues/new?template=false_positive.yml)
- Usage question or design discussion:
  [start a discussion](https://github.com/EhsanAzish80/Nick/discussions)
- Feature proposal:
  [open a feature request](https://github.com/EhsanAzish80/Nick/issues/new?template=feature_request.yml)

Community support is best effort. Please do not send duplicate requests through
multiple channels.

## Security reports

Do not report vulnerabilities publicly. Follow the private process in
[SECURITY.md](SECURITY.md).

## What not to upload

- live malware or suspicious archives;
- signing certificates, provisioning profiles, API tokens, or private keys;
- full mailbox contents or browsing history;
- exported alert JSON that has not been reviewed for personal information.

Coordinate sensitive sample transfer privately only after a maintainer requests
it.
