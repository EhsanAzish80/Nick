# Nick 5.1 first threat-intelligence bundle

This checklist keeps signing key material outside the repository and keeps Strict Mode off until the signed bundle is independently verified on an installed candidate.

1. Create or select the production Ed25519 private key in protected local storage. Do not copy it into this repository, build products, CI variables, logs, or the website tree.
2. Build and verify the bundle against Nick's compiled production public key:

   ```bash
   Scripts/build-first-threat-bundle.py \
     --private-key /absolute/protected/path/nick-ed25519.pem \
     --output /private/tmp/nick-threat-bundle-v1.json \
     --version 1
   ```

   The compiled Ed25519 public key is
   `vhmPD4eSgTVFeCc6tR7SZdceirBiJ0n29taAnM/s9m4=`. The publisher emits only
   `payloadData` (the exact signed bytes) plus `signature`; there is no legacy
   decoded-payload verification path. `--verification-public-key` is a test-only
   option and is rejected unless `NICK_BUNDLE_TEST=1`.

3. Review the generated payload: version increases monotonically, validity is at most 180 days, every blockable rule is high-confidence, and the exact-hash catalog matches the shipped catalog.
4. Publish the verified bytes to `https://3nsofts.com/nick/threat-intelligence/current.json`. Record the SHA-256, byte length, bundle version, issue time and expiry in the private release packet.
5. On a notarized installed candidate, enable bundle updates while Strict Mode remains off. Confirm Diagnostics reports the expected bundle version and provenance after relaunch.
6. Run the signed-rule replay and benign corpus. Confirm only the signed high-confidence rules are eligible for Strict Mode; exact known-malware hashes remain protected independently.
7. Enable Strict Mode manually for the declared test user. Confirm a signed high-confidence fixture is blocked and a review-only fixture is not blocked.
8. Exercise the kill switch: disable Strict Mode, verify prevention stops immediately while detection remains, then remove or expire the hosted bundle and confirm Nick keeps the last-known-good bundle without accepting rollback.
9. Enable Strict Mode for wider use only after the installed replay, benign corpus and kill-switch evidence are attached to the release record.
